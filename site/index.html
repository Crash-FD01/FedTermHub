FedTermHub riunisce terminali locali, sessioni SSH, desktop RDP e VNC, file SFTP e un vault cifrato per le credenziali, con le sessioni organizzate in cartelle. Pensato per chi amministra sistemi. Open source, gratuito, per Linux.

FedTermHub brings local terminals, SSH sessions, RDP and VNC desktops, SFTP files and an encrypted credential vault together, with sessions organized in folders. Built for system administrators. Open source, free, for Linux.

Debian 12+, Ubuntu 22.04+, Linux Mint 21+ and derivatives, Fedora 43+, RHEL/AlmaLinux/Rocky 9+, openSUSE Tumbleweed and Leap 16+; x86_64 and ARM64. One command: adds FedTermHub's signed repository and installs it.

Preferisci farlo a mano?Rather do it by hand?

Debian, Ubuntu, Mint

sudo install -d -m 755 /etc/apt/keyrings
sudo curl -fsSL @SITE_URL@/fedtermhub.asc -o /etc/apt/keyrings/fedtermhub.asc
echo "deb [signed-by=/etc/apt/keyrings/fedtermhub.asc] @SITE_URL@/apt ./" | sudo tee /etc/apt/sources.list.d/fedtermhub.list
sudo apt update && sudo apt install fedtermhub

Fedora

sudo rpm --import @SITE_URL@/fedtermhub.asc
sudo curl -fsSL @SITE_URL@/fedtermhub.repo -o /etc/yum.repos.d/fedtermhub.repo
sudo dnf install fedtermhub

Silverblue, Kinoite, Bazzite: come sopra, poi rpm-ostree install fedtermhub e riavvia.

Silverblue, Kinoite, Bazzite: as above, then rpm-ostree install fedtermhub and reboot.

RHEL, AlmaLinux, Rocky

sudo rpm --import @SITE_URL@/fedtermhub.asc
sudo curl -fsSL @SITE_URL@/fedtermhub-universal.repo -o /etc/yum.repos.d/fedtermhub.repo
sudo dnf install fedtermhub

openSUSE

sudo rpm --import @SITE_URL@/fedtermhub.asc
sudo zypper addrepo --refresh @SITE_URL@/fedtermhub-universal.repo
sudo zypper install fedtermhub

AES-256-GCM. Passwords never land in the session file or on a process command line.

I file seguono il terminaleFiles follow the terminal

Accanto a ogni sessione SSH c'è l'albero dei file remoti. Fai cd nella shell e l'albero si sposta con te; trascini un file dal tuo computer per caricarlo, fai doppio clic per scaricarlo.

Next to every SSH session there's the remote file tree. cd in the shell and the tree moves with you; drag a file from your computer to upload it, double-click to download.
